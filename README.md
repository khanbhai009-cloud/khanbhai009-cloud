### Featured Projects

#### 📌 Pinteresto — Autonomous Pinterest Growth Engine *(production, private)*

A multi-agent pipeline that runs Pinterest accounts end-to-end:

- **Mastermind graph (LangGraph):** CMO strategy agent → board selection → product router → executor
- **Product Router (v4):** every new pin is matched against a product catalogue (rule scoring + LLM judge); the right digital product is attached as the pin's destination — no match, no forced link
- **Trend system:** trend tracking with a feeder that grows the prompt library daily
- **AI media pipeline:** FLUX image generation with layered fallbacks
- **Publishing** via Make.com webhooks; **control** via a Kotlin Android app (schedules, trends, products, logs)
- Live storefront: [pinteresto.vercel.app](https://pinteresto.vercel.app)

`Python` · `FastAPI` · `LangGraph` · `Gemini` · `Groq` · `Google Sheets API` · `Kotlin / Jetpack Compose` · `Make.com` · `Render`
